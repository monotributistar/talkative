## Objetivo

Agregar los modelos persistentes `Principal`, `Subject`, `Delegation`,
`Conversation`, `ConversationTurn`, `Case` y `CaseField`, junto con repositorios
tenant-safe para crear y recuperar un expediente básico.

## Contratos

- Consume: constitución, spec Feature 001 y contratos T002.
- Produce: entidades Prisma y API interna de repositorio de casos.
- No puede cambiar: contratos T002, `backend/src/app.ts`, rutas, adaptadores ni
  lógica conversacional.

## Escenarios obligatorios

```gherkin
Scenario: expediente del tenant correcto
  Given un principal, un dependiente y un caso sintéticos del tenant A
  When el repositorio recupera el caso para tenant A
  Then devuelve el expediente y sus relaciones

Scenario: aislamiento entre tenants
  Given un caso del tenant A
  When se intenta recuperar desde tenant B
  Then el repositorio no lo devuelve

Scenario: relación inválida
  Given un subject que no pertenece al principal indicado
  When se intenta crear un caso
  Then la operación es rechazada
```
