# T005 — Motor de turno estructurado

**Owner:** Conversation  
**Estado:** done  
**Depende de:** T002  
**Archivos permitidos:** `backend/src/conversation/**`,
`specs/001-medical-appointment/fixtures/conversation-*`,
`specs/001-medical-appointment/tasks/T005.md`

## Objetivo

Implementar un motor determinista que reciba el estado redactado de un caso y
produzca exactamente un `TurnDecision` válido. No puede persistir, ejecutar
herramientas ni cambiar estados.

## Contratos

- Consume: `turn-decision.schema.json` y fixtures T002.
- Produce: tipo TypeScript equivalente y función pura de decisión.
- No puede cambiar: contratos T002, Prisma, rutas, `AgentRunner` ni adaptadores.

## Escenarios obligatorios

```gherkin
Scenario: falta un dato
  Given un caso sin rango horario
  When se decide el siguiente turno
  Then produce ask_field para preferred_time_range

Scenario: datos listos sin consentimiento
  Given todos los campos mínimos confirmados
  And no existe consentimiento vigente
  When se decide el siguiente turno
  Then produce request_consent

Scenario: solicitud clínica o urgente
  Given un mensaje clasificado fuera del alcance administrativo
  When se decide el siguiente turno
  Then produce handoff con URGENT_OR_CLINICAL_REQUEST
```
